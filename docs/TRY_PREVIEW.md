# 从测试包试用，不改日常开图

这不是新版开图安装器。下载私用的 `kaitu-novel-workspace-0.4.0-alpha.1.tgz`，不必解压或覆盖原插件。下面是 macOS 示例；需要 Node 24.9+、pnpm 11.22.0，原生 DSH 命令 `dsh` 对应已验证版本 0.2.2-rc.1。

在**同一个**终端运行：

```sh
archive="$HOME/Downloads/kaitu-novel-workspace-0.4.0-alpha.1.tgz"
export DSH_HOME="$(mktemp -d)"
export DSH_AGENTS_HOME="$DSH_HOME/agents"
dsh plugin --profile web add "$archive"
dsh web --port 3082
```

若模型或工作区引导第一次出现，这是全新测试环境的预期表现；不要把真实稿或日常凭据拷进来。打开终端输出的本机链接，在新建的合成作品目录完成引导，点击侧栏 **写作 → 打开作品目录**。这里是 Oh Story 的文件树和正文编辑器。可以自己编辑，或在配置了所选模型后用 `/story-review` 发起辅助审稿。若 3082 已占用，换一个空闲端口，不要停止其他实例。

先试合成句：“环廊匀速且不停留，每圈恰好 8 分钟。她同样走了 2 圈，恰过 19 分钟。”人工确认范围、圈数、无延迟/无例外、每条引文出处后，请它只报告矛盾，不改正文。**看见 16 分钟的依据再自己选择**：改正文副本、补 3 分钟的缘由、或保留原文。没有明确确认，或条件并不一致，就不要判错。启动、选目录和编辑器不等于真实模型已经配置；向远程模型发送文字则遵循该模型的数据政策。

关闭终端服务不会卸载或替换日常开图。这个临时位置只用于验收，不适合保存唯一一份真稿；若需要再次进入同一测试环境，应先记下本终端 `echo "$DSH_HOME"` 的路径。开发者源码构建和上游约束见[项目首页](../README.md)，宿主集成证据见[浏览器嵌入](KAITU_EMBED.md)。
